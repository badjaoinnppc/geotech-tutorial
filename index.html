From field sheet to signed report — step by step

This guide walks you through GeoTech Report Studio screen by screen. You'll enter Advanced Dynamic Cone Penetration Test (ADCPT) readings, check the calculations and charts, and print a complete A4 geotechnical engineering report.

What the program does

On site, the field technician records hammer drops and gauge readings for each depth on the soil data sheet. GeoTech Report Studio turns those readings into the full engineering report, and does the repetitive work for you:

  • You type each reading once. Every table, chart and report page is built from that one entry. Correct a reading and every page updates.
  • Calculations are automatic and transparent. The program calculates impact load, settlement, ultimate bearing capacity (USBC) and allowable bearing capacity (ASBC), and shows the formula behind every number.
  • Charts are drawn for you: load–settlement curves for every depth, and the depth–ASBC profile.
  • Reports follow the familiar layout: cover page, bearing-strength table, load–settlement sheets, depth–ASBC curve, soil profile and field data sheet, ready for A4 paper.
  • The engineer stays in control. Nothing is certified until the engineer has reviewed and signed the calculation method. Anything still unconfirmed is clearly marked Requires Engineer Verification.

This is the complete program. Its built-in demonstration project (Load reference example) uses fictional sample names, like the screenshots on this page. Results are certified only after the responsible engineer signs the calculation method inside the program (section 12).

What you need

  • A Windows 10 or Windows 11 computer (64-bit).
  • About 400 MB of free disk space.
  • The installer file: download it above, or use the copy from your software provider (for example on a USB drive).

Steps

  1. Download the installer (button above) and double-click it. If your browser asks, choose Keep: some browsers warn about new programs that are not yet widely downloaded.
  2. If Windows shows "Windows protected your PC", click More info, then Run anyway. The installer isn't yet signed with a commercial certificate, which is why Windows asks. Only do this for an installer you received directly from your provider.
  3. Choose "Only for me" (no administrator password needed) and click Next. You can keep the suggested folder.
  4. Click Install and wait about 20 seconds, then click Finish.
  5. Start the program from the GeoTech Report Studio icon on the desktop or in the Start menu.
Where your work is kept

Everything you enter is stored on this computer in %APPDATA%\GeoTech Report Studio. Uninstalling the program does not delete your projects or backups. To see the folders, use Help → Open data folder inside the program.

Test it offline once

The program is built to work without internet. To be sure, unplug the network or switch off Wi-Fi the first time you use it: everything works the same.

2A tour of the screen

On first start you'll see the Dashboard. It lists your projects (empty at first).

Saving is automatic

There is no "Save" button for field data: everything is saved as you type. Forms such as project details and the soil profile have a Save button, and the program warns you if you try to leave with unsaved changes.

The menu bar at the top of the window gives you:

  • File → Back up now: an instant backup.
  • View → Zoom in/out: make everything larger on small screens.
  • Help → User guide, Open log folder and About.

3Company details (do this once)

Your business details appear on every report page: the cover, the footers and the signature blocks. Enter them once in Settings & backup.

The program never creates signatures or seals

Signature and seal images appear on reports only if you upload them yourself. Never upload an engineer's seal without their permission.

You can also set the report colours and the paper size (A4 by default; Letter and Legal are available). To keep two different letterheads, use Duplicate template.

4Create a project

A project is one investigation for one client: for example "Proposed Three-Storey Commercial Building". It can hold any number of drillholes.

  1. On the Dashboard, click + New project.
  2. Fill in the fields. Only the title is required, and you can complete the rest later.
  3. Click Create project. The program opens the project at the Drillholes page.

Later, open Project details in the sidebar to add the engineer in charge, the prepared-by and reviewed-by names, notes and the project status (Draft → Field data entry → For engineer review → Approved → Issued).

5Add drillholes

Each test location is a drillhole: DH-01, DH-02 and so on. The program suggests the next code for you.

  1. In the project, click Drillholes in the sidebar, then + Add drillhole.
  2. Check the code, then enter the date, the start and finish times, the weather and who conducted the test.
  3. Check the three engineering settings (see below), then click Save. Repeat for each drillhole.

Starting a new drillhole

  1. Click a cell (or move to it with the arrow keys).
  2. Type the value. Press Tab to go to the next cell, or Enter to go down. At the last row, Enter adds a new row for another drop.
  3. To add the next depth, click + Add depth. It uses the interval shown on the toolbar (1 m by default), so after depth 3 it adds depth 4.
  4. Watch the badge at the top right: All changes saved means everything is stored.

Checks, warnings and errors

The program checks every reading as you type. Problems are coloured in the grid and listed below it:

  • Amber = warning. Something looks unusual, such as a missing reading or a reading higher than the previous one (the gauge should only go down). The data is still saved, but check it.
  • Red = error. The value can't be used, for example text instead of a number. The latest changes are not saved until you correct it.
Made a mistake? Undo it.

Ctrl+Z undoes your last change and Ctrl+Y redoes it. You can undo many steps, including a paste.

Other useful tools:

  • Insert row: add an extra drop at the same depth.
  • Duplicate depth: copy a whole depth to the end, ready to edit.
  • Delete rows / Delete depth: remove what you don't need.
  • Ctrl+D: fill the selection down. Select a column range with Shift+arrows first.

There is no depth limit: you can record holes deeper than 10 m.

7Soil profile

Describe the soil layers found in the drillhole. These descriptions are printed in the report's classification column, next to the depth–ASBC curve and on the soil profile page.

Classification is your decision

The program never guesses soil type or consistency from the penetration readings. What you type here is what appears on the report.

8Calculations

The Calculations page shows, for every depth, the load–settlement values and the bearing capacity. Most of the work is automatic. The one thing you add is the critical load for each depth.

How the numbers are made

These are the formulas the program uses (shown with the reference report's values):

F-01 · Impact load for each drop
I = M × √(27 × H)
M = hammer mass (kg), H = drop height in metres. Example: 30 kg dropped 300 mm → 30 × √(27 × 0.3) = 85.38 kg. With no drop (H = 0), I = M = 30 kg.
F-02 · Settlement produced by each drop
s = previous reading − new reading
Readings follow in the order A1, A2, A3, then B1… then C1…, starting from the initial reading. Example: 500 → 475 gives a settlement of 25 mm.
F-03 to F-05 · Bearing capacity from the critical load
P = I × 0.01  ·  USBC = P ÷ (π d² ÷ 4)  ·  ASBC = USBC ÷ SF
Example: critical load 180 kg → P = 1.800 kN → bearing area of a 0.05 m bit = 0.0019635 m² → USBC = 916.73 kPa → with SF 3.0, ASBC = 305.58 kPa.
F-06 · Critical load at the critical settlement (25 mm)
Determined by the engineer for each depth
The engineer reads the critical load from the load–settlement data and enters it. The program records who entered it, why, and when.

The full details of every formula (inputs, units, rounding and status) are on the Methodology page.

Entering critical loads

  1. Click Load–settlement on a row to see that depth's drops, loads and settlements. The Graphs page shows the same data as a curve.
  2. Decide the load at which the critical settlement (25 mm) is reached.
  3. Click Enter critical load, type the load in kg, a short reason (the basis) and your name, then click Save.
  4. USBC and ASBC appear on that row immediately. Repeat for every depth.
"Matches reference · not signed off"

This blue badge means the number was calculated correctly with the formulas from the reference report, but the engineer has not yet approved the method. After sign-off (section 12) the badge changes to Certified.

9Graphs

11Reports and PDF

The Reports page builds the complete report from everything you've entered. The preview on the right is exactly what the PDF and the printer will produce.

If a page is outlined in red

Its contents don't fit on the paper, for example a very long soil description. The page numbers are listed above the preview. Shorten the text and the outline disappears. The program never silently cuts text off.

Printing tip

When printing a PDF from a PDF viewer, choose Actual size / 100%, not "Fit to page", so the pages print at exactly A4.

What the pages look like

Click any page to enlarge it, or open the complete 18-page sample report (PDF).

There is also an optional Engineer's notes and conclusions page with signature lines. Tick it in the page list to include it.

Saving issued versions

When you send a report to a client, click Save version…. The program stores the PDF together with a frozen copy of all the data behind it. If you edit the project later, the saved version does not change.

12Engineer sign-off: making results certified

The program comes with the calculation method rebuilt from the reference report. It reproduces the reference numbers exactly, but it is not certified until the responsible engineer reviews and signs it. This section is for the engineer.

Why this step exists

A report should only call results "certified" when a qualified engineer has confirmed the method. Until then, every screen and report page says so clearly. After sign-off, the warnings are replaced by the engineer's name, licence number and date.

Step by step

  1. Click New draft from 0.1-draft…, keep the suggested name 1.0, then click Create draft.
  2. Review the parameters, such as the 0.01 kN/kg conversion. Change them only if your method differs.
  3. In Formula review, choose Engineer approved for each formula you accept, and add a note if useful.
  4. Write your answers to the open questions, especially Q-03: how you obtain the critical load.
  5. Click Review & sign…, enter your name and PRC licence number, tick the confirmation and click Sign and publish.
  6. Click Apply to drillholes… to recalculate existing drillholes with the signed version.
Protect the computer

The sign-off is a recorded statement inside the program, not a legal digital signature: anyone using the computer could type a name. Keep the computer password-protected. Each signed version is fingerprinted, so if it is changed outside the program it is marked "Integrity check failed" and can't be used.

15Complete worked example: field sheet to PDF

A checklist for a typical two-drillhole job. With the readings already in Excel it takes about 15 minutes.

  1. Dashboard → + New project. Title "Proposed Three (3) Storey Commercial Building", client, location, dates → Create project.
  2. Drillholes → + Add drillhole twice (DH-01 and DH-02). Enter times and who conducted the test. Keep bit 0.05 m, SF 3.0 and 25 mm unless your test differs.
  3. Field data → DH-01. Click the first depth cell and paste the readings from Excel (Ctrl+V). Clear every red cell, check the amber ones, and wait for All changes saved. Repeat for DH-02.
  4. Soil profile. Add the layers (e.g. 0–8.8 m CL lean clay, stiff to very stiff; 8.8–10 m lithified clay, extremely weak rock) → Save profile.
  5. Calculations. For each depth, look at the load–settlement values and click Enter critical load. With 180 kg at 2 m you should see ASBC = 305.58 kPa.
  6. Graphs. Check the depth–ASBC profile and the load–settlement curves. If needed, fix the axes in Chart settings (e.g. ASBC 0–1000 kPa).
  7. Site photographs. Add the site and drillhole photos and caption them.
  8. Reports. Scroll through the preview. Make sure no page is outlined in red, then Export PDF….
  9. Engineer. Check the PDF. If the method is already signed, results are certified; if not, see section 12.
  10. Issue. Click Save version… with a label such as "Rev. 0 — issued to client", then back up to a USB drive.
Practise first

Click Load reference example on the Dashboard to get a ready-made project with real readings. You can try every step without affecting your own work, then delete it from Project details.

17Questions and problems

Windows says "Windows protected your PC" when I install

The installer is not yet signed with a commercial certificate. Click More info → Run anyway, but only for the installer you received from your provider.

How can I check the download is genuine?

The SHA-256 checksum of the file must be d4d1bd134a0dca0b56aaf4963d101c3f159c638d484e75a975c221e01916be21. In Windows PowerShell, run Get-FileHash .\GeoTech-Report-Studio-Setup-0.10.0-public.exe in your Downloads folder and compare the two.

The badge says "Not saved — correct the red cells"

A cell contains something that isn't a number, such as "3x8". Click the line in the Checks list under the grid to jump to it, then fix or clear it. Saving resumes automatically.

A reading is marked amber: "higher than the previous reading"

Gauge readings should get smaller with each drop. A higher reading usually means a typing error, or occasionally a rebound. Check the field sheet: if the value is right, you can leave it, because warnings don't stop saving.

The ASBC for a depth is missing

Enter the critical load for that depth on the Calculations page. Depths without one are never filled in automatically.

My report still says "Requires Engineer Verification"

The calculation method for that drillhole hasn't been signed by the engineer, or not all formulas are approved. See section 12. Also check that the drillhole uses the signed version: Drillholes → Settings → Methodology version.

A report page is outlined in red

Its contents don't fit on the page, usually because of a very long soil description or note. Shorten the text; the outline disappears as soon as it fits.

The printed page is smaller or larger than A4

Print from the PDF at Actual size / 100%, not "Fit to page". Check the paper size in Settings (A4 by default).

Can I use the program on two computers?

Yes. Install it on both and move projects with Export archive and Import archive. Each computer keeps its own data. Don't edit the same project on both at once.

Does the program send my data anywhere?

No. It works completely offline and network access is blocked by design. Your data stays in %APPDATA%\GeoTech Report Studio on your computer.

Something went wrong. What should I send to support?

Use Help → Open log folder and send the file app.log. It contains event and error messages, not your measurements.

18Glossary

ADCPT
Advanced Dynamic Cone Penetration Test: a hammer is dropped from set heights and the penetration is measured, to estimate soil bearing capacity.
NGL
Natural ground level: the first test depth, at the surface.
Drop height (H)
Height in mm from which the hammer falls.
Hammer mass (M)
Mass of the drop hammer in kg (30 kg in the examples).
Initial reading
Gauge reading before the first drop at a depth (500 mm in the examples).
Tests A, B, C
Three successive test series at each depth. Their readings continue from one another.
Settlement
How far the cone moved down with one drop: previous reading minus new reading (mm).
Impact load (I)
Load produced by a drop: I = M × √(27 × H), H in metres.
Critical settlement
The settlement (25 mm by default) at which the critical load is taken.
Critical load
The load at the critical settlement, determined by the engineer for each depth.
USBC
Ultimate soil bearing capacity (kPa): load divided by the bearing area of the drill bit.
SF
Safety factor (3.0 by default).
ASBC
Allowable soil bearing capacity (kPa) = USBC ÷ SF. The value used for design.
USCS
Unified Soil Classification System, e.g. CL = lean clay.
Δ and N
Values recorded on the field data sheet (penetration and number of blows), printed as entered.
Exhibit
A numbered set of report pages, e.g. B-1.2 for the load–settlement sheets of DH-01.
Methodology version
A recorded set of formulas and settings. Once signed by the engineer it can't be changed, and reports keep the version they were calculated with.
Certified
Calculated with a signed methodology version in which all bearing formulas are approved, with a critical load entered by the engineer.
